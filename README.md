# Health Prediction Application

## Overview
A Streamlit-based Health Prediction Application that allows users to manage patient records and generate AI-powered health remarks based on blood test values.

## Features
- Create Patient Records
- View Patient Records
- Delete Patient Records
- AI-generated Health Predictions
- SQLite Database Storage
- Input Validation

## Tech Stack
- Python
- Streamlit
- SQLite
- OpenAI API
- Pandas

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py
